O MCP tem **70 tools** com **190 ações**, em dois grupos:

- **Tools da API v2** (47): produtos, ofertas, cupons, checkouts, pedidos, assinaturas e saques. São o padrão: cada tool é um endpoint da [API v2](/introduction), executado pela Ticto com as permissões da sua conexão. O agente prefere estas quando elas resolvem o pedido.
- **Tools do painel** (23): o que a API v2 ainda não cobre (funis, eventos, relatórios, financeiro, webhooks, integrações, área de membros, agentes de IA, e a criação de produto e oferta com tipos especiais). Cada uma agrupa várias ações no argumento `action`. Elas saem do MCP à medida que a API v2 passa a cobrir cada área.

O agente só recebe as tools das áreas liberadas e das ações ligadas para aquela conexão em [Ferramentas MCP](/mcp/manage). A descrição completa de cada tool, com os campos aceitos, vem na própria tool, na lista que o servidor entrega ao agente.

## Tools da API v2

Cada tool recebe os ids da rota (`hash`, `code`, `id`) como argumentos, os filtros em `query` e, na criação, o corpo em `body`:

```json
{ "name": "list_offers", "arguments": { "hash": "PA5DB5141" } }
{ "name": "orders_history", "arguments": { "query": { "page": 2, "filter": { "status": "authorized" } } } }
```

<Accordion title="Área de membros: portais e turmas" icon="wrench">

Como funciona a área de membros da Ticto: o PORTAL é a área do aluno (subdomínio próprio, cores e vitrine). O CONTEÚDO é o curso: tem MÓDULOS, e dentro deles AULAS (texto, vídeo, arquivo) e QUIZZES; pode ter certificado. A TURMA fica dentro de um portal e define QUAIS conteúdos o aluno acessa e QUANDO (liberação por data ou por dias após a compra). O aluno entra numa turma ao comprar uma OFERTA vinculada a ela (na oferta: members_classroom_id + days_of_access), por cadastro manual ou por ACESSO GRATUITO. O produto se liga ao portal (link_product). A VITRINE organiza os conteúdos em seções na home do portal; conteúdo que o aluno não tem pode mostrar a página de vendas. AVISOS vão para os alunos das turmas escolhidas. Fluxo típico para lançar um curso: criar conteúdo → módulos → aulas → criar/usar uma turma no portal → liberar o conteúdo na turma (set_classroom_contents) → vincular a oferta à turma (offers_write update). Portais, turmas, vitrine, avisos, próximos lançamentos e acessos gratuitos. \{portal\}, \{classroom\}, \{section\}, \{notice\}, \{release\}, \{free_access\} = ids. Vincular portal a produto: products \{product\}.
