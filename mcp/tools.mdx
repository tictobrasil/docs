O MCP tem **180 tools**, todas da API v2. Funis de upsell (flow) não estão no MCP: são configurados pelo painel.

Cada tool é um endpoint da [API v2](/introduction), executado pela Ticto no mesmo processo, com as permissões da conexão do agente. Os ids são os públicos da v2: produto pelo `hash` (ex.: `P5E501A73`), oferta pelo código (ex.: `O64522FA4`), checkout pelo `uuid`, agente e persona pelo código. As respostas vêm no formato da v2: `{object, id, ...}` e listas em `{object: "list", data, meta}`.

Nas edições, mande **só os campos que mudam**: o resto fica como está.

O agente só recebe as tools das áreas liberadas e das ações ligadas para aquela conexão em [Ferramentas MCP](/mcp/manage). A descrição completa de cada tool, com os campos aceitos, vem na própria tool, na lista que o servidor entrega ao agente.

## Tools da API v2

Cada tool recebe os ids da rota como argumentos, os filtros em `query` e o corpo em `body`:

```json
{ "name": "list_offers", "arguments": { "hash": "PA5DB5141" } }
{ "name": "update_coupon", "arguments": { "product": "P5E501A73", "coupon": "13158", "body": { "discount": 25 }, "confirm": true } }
```
